PrepTrack by UD — Web app (installable)

HOW TO OPEN
- Easiest: open index.html in Chrome or Edge.

HOW TO INSTALL AS AN APP (Windows and Android)
- The "Install app" button appears in the header when the app is served from a
  web address (https). Upload this whole folder to any free static host
  (for example Netlify Drop or GitHub Pages), open that address in Chrome or Edge,
  then choose Install app (or the browser menu > Install / Add to Home screen).
- Opening index.html straight from your disk does not allow installation, because
  browsers only install apps from web addresses. Use the Windows or Android
  builds below if you want an app without hosting.

Keep the same address when you update the app so your saved progress stays with it.
Use Profile > Create backup to move progress between devices.
